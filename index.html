Frequenty Asked Questions

How I can use LiteBash Library as Asset Library

Step 1: In the main top menu, choose Edit > Preferences.

Step 2: In the sidebar menu, choose File Paths.

Step 3: In the Asset Library section, click the [+] icon in the top-right corner.

Step 4: Select the folder containing the LiteBash Library content.

Step 5: In the main Blender window, in any area, choose Data: Asset Browser from the top-left corner, or use the shortcut Shift + F1.
